# Simple Bash Ping Automation Script

This project is a basic Bash automation script that sends ICMP (Ping) packets to a domain name or IP address provided by the user via interactive terminal input.

## 🚀 Features
- **Dynamic Input:** Prompts the user for a target domain or IP using the `read` command.
- **Address Confirmation:** Prints the target address to the terminal before initiating the request.
- **Count Limit:** Limits ICMP requests to 4 packets using the `-c 4` flag to prevent infinite execution.
